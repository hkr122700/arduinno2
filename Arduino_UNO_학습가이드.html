준비부터 차근차근

이 자료는 Arduino UNO R3 (5V, ATmega328P)를 기준으로 합니다. 외부 라이브러리는 필요하지 않습니다.

준비물: UNO R3, 데이터 전송용 USB 케이블, 브레드보드, 점퍼선, 일반 표시용 LED 2개 이상, 330 Ω 저항 2개 이상, 조건에 맞는 신호등 모듈. 모듈 대신 LED 3개로 구성하려면 저항도 3개 준비하세요.

  1. USB와 외부 전원을 분리한 상태에서 해당 예제의 연결표대로 배선합니다.
  2. USB를 연결하고 Arduino IDE에서 Arduino Uno 보드와 해당 포트를 선택합니다.
  3. 아래 예제 하나의 코드 전체를 빈 스케치에 붙여 넣습니다. 여러 예제의 setup()과 loop()를 합치지 마세요.
  4. 검증(컴파일) 후 업로드하고 LED 동작을 확인합니다. 다음 예제로 이동할 때 전원을 빼고 배선을 변경하세요.

HTML을 여는 것만으로 보드가 동작하지는 않습니다. Arduino IDE에서 별도로 업로드해야 합니다.

회로를 이해하는 세 가지

핀D11·D12·D13은 디지털 출력으로 사용할 수 있습니다. OUTPUT 설정 후 HIGH는 약 5V, LOW는 약 0V입니다.
저항LED에 흐르는 전류를 제한합니다. 이 자료의 일반 LED는 330 Ω을 사용합니다. 저항은 방향이 없습니다.
GND0V 기준점이자 전류가 돌아오는 경로입니다. UNO와 LED 또는 모듈이 같은 GND를 공유해야 합니다.

D11은 PWM도 지원하지만 여기서는 digitalWrite()로 켜고 끄기만 합니다. D12와 D13도 같은 방식으로 사용합니다. 보드에 인쇄된 11, 12, 13을 찾으세요. 헤더의 구멍 순서를 세어 정하는 번호가 아닙니다.

디지털 핀 → 330 Ω → LED + → − → GND

LED의 긴 다리는 보통 양극(+), 짧은 다리와 몸체의 평평한 면은 음극(−)입니다. 다리가 잘렸다면 부품 사양을 확인하세요. 저항은 LED 앞이나 뒤 어느 쪽이든 직렬이면 됩니다.

예: 순방향 전압이 2V인 LED는 (5V − 2V) ÷ 330 Ω ≈ 9mA입니다. LED마다 전압이 다릅니다. UNO R3의 핀당 전류 사양은 20mA이므로 그보다 낮게 사용하며, 많은 LED를 동시에 구동할 때는 전체 전류 제한도 확인해야 합니다.

코드 읽기: setup()은 시작할 때 한 번, loop()는 계속 반복됩니다. pinMode(..., OUTPUT)은 출력 설정, digitalWrite()는 켜기/끄기, delay(1000)은 1초 대기입니다. delay() 동안 이 스케치의 다음 처리는 기다립니다.

브레드보드, 같은 줄을 구별하세요

일반적인 브레드보드에서는 같은 숫자의 a–e 다섯 구멍이 연결되고, f–j 다섯 구멍이 따로 연결됩니다. 가운데 홈을 가로질러 연결되지 않으며, 서로 다른 숫자의 줄도 분리됩니다.

옆의 +/− 전원 레일은 보통 길게 연결되지만 중간에서 끊어진 제품도 있습니다. 색상은 표시일 뿐, 전원이 자동으로 생기지 않습니다. 이번 실습은 + 레일 없이 진행하며, 사용하는 − 레일 구간을 UNO GND에 연결합니다.

예제 01을 실제 구멍에 꽂는 순서

출발 / 부품연결할 곳
UNO D13 → 점퍼선a10
330 Ω 저항의 두 끝b10 과 b15
LED 긴 다리(+)c15
LED 짧은 다리(−)c16
a16 → 점퍼선− 레일의 사용 구간
UNO GND → 점퍼선같은 − 레일 구간

전류 경로는 D13 → 10번 줄 → 저항 → 15번 줄 → LED → 16번 줄 → GND입니다. 저항 양 끝이나 LED 양 다리를 같은 연결 묶음에 꽂으면 부품이 우회되므로 주의하세요.

예제 02는 같은 방식을 두 벌 만듭니다. A는 D11 → a10, 저항 b10–b15, LED c15(+)–c16(−), a16 → GND로 연결합니다. B는 D12 → a20, 저항 b20–b25, LED c25(+)–c26(−), a26 → 같은 GND로 연결합니다. 예제 01의 D13 점퍼선은 제거합니다.

01 · LED 기본 ON / OFF

D13에 연결한 LED를 1초 켜고, 1초 끕니다. 계속 켜려면 loop() 안에 HIGH 명령만, 계속 끄려면 LOW 명령만 남기세요.

출발 / 부품연결할 곳
D13330 Ω 저항 → LED 긴 다리(+)
LED 짧은 다리(−)GND 공통 레일 → UNO GND
UNO R3의 보드 내장 L LED도 D13과 연동됩니다. 외부 LED에는 반드시 별도의 저항을 연결하세요. 내장 LED만 시험할 때는 외부 배선이 필요 없습니다.
Arduino C++ · 전체 스케치
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // 켜기
  delay(1000);                // 1초 기다리기
  digitalWrite(LED_PIN, LOW);  // 끄기
  delay(1000);
}

02 · LED 2개 홀짝 번갈아 점등

홀수 핀 D11의 LED A와 짝수 핀 D12의 LED B가 0.5초씩 번갈아 켜집니다. 여기서 홀짝은 핀 번호를 뜻합니다. D13은 이 예제에서 사용하지 않습니다.

출발 / 부품연결할 곳
D11 · 홀수330 Ω 저항 A → LED A 긴 다리(+)
D12 · 짝수330 Ω 저항 B → LED B 긴 다리(+)
LED A·B 짧은 다리(−)각각 GND 공통 레일 → UNO GND
LED마다 저항 1개씩 필요합니다. 두 LED가 저항 하나를 공유하지 않게 하세요. 두 LED의 음극은 같은 GND 레일을 공유해도 됩니다.
Arduino C++ · 전체 스케치
const int ODD_LED = 11;
const int EVEN_LED = 12;

void setup() {
  pinMode(ODD_LED, OUTPUT);
  pinMode(EVEN_LED, OUTPUT);
  digitalWrite(ODD_LED, LOW);
  digitalWrite(EVEN_LED, LOW);
}

void loop() {
  digitalWrite(EVEN_LED, LOW); // 먼저 반대쪽을 끄기
  digitalWrite(ODD_LED, HIGH);
  delay(500);

  digitalWrite(ODD_LED, LOW);
  digitalWrite(EVEN_LED, HIGH);
  delay(500);
}

03 · 신호등 모듈

빨강 3초 → 초록 3초 → 노랑 1초 순서로 반복합니다. 실제 도로의 제어 규칙을 구현한 것이 아니라 LED 출력 연습용입니다.

출발 / 부품연결할 곳
D11모듈 R (빨강)
D12모듈 Y (노랑)
D13모듈 G (초록)
UNO GND모듈 GND / − (공통 음극)
이 연결표는 5V UNO 호환 · 공통 음극 · HIGH 점등 · 각 색 전류 제한 저항 내장 · 채널당 20mA 이하인 4핀 R/Y/G/GND 모듈에만 적용합니다. 제품 설명과 실크 인쇄를 먼저 확인하세요. G는 초록 신호이며 GND와 다릅니다. 핀의 물리적 순서는 제품마다 다릅니다. 공통 양극, LOW 점등, 별도 VCC가 있는 모듈은 이 배선과 코드의 적용 대상이 아닙니다.
Arduino C++ · 전체 스케치
const int RED_PIN = 11;
const int YELLOW_PIN = 12;
const int GREEN_PIN = 13;

void allOff() {
  digitalWrite(RED_PIN, LOW);
  digitalWrite(YELLOW_PIN, LOW);
  digitalWrite(GREEN_PIN, LOW);
}

void showLight(int pin, unsigned long durationMs) {
  allOff();
  digitalWrite(pin, HIGH);
  delay(durationMs);
}

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(YELLOW_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  allOff();
}

void loop() {
  showLight(RED_PIN, 3000);
  showLight(GREEN_PIN, 3000);
  showLight(YELLOW_PIN, 1000);
}

모듈 대신 일반 LED 3개를 쓴다면

같은 코드를 사용합니다. D11 → 330 Ω → 빨강 LED(+), D12 → 330 Ω → 노랑 LED(+), D13 → 330 Ω → 초록 LED(+)로 연결하고, 세 LED의 음극은 모두 UNO GND로 연결합니다. 각 LED에 저항을 하나씩 사용합니다. 저항이 없는 수동 공통 음극 모듈도 제조사 사양이 이 방식과 맞는 경우에만 색상 신호별로 외부 저항을 추가하세요.

안 켜질 때 확인할 순서

  1. 업로드 성공? 보드·포트 선택과 데이터 USB 케이블을 확인합니다.
  2. 핀 번호 일치? 예제 01은 D13, 예제 02는 D11·D12, 신호등은 빨강 D11·노랑 D12·초록 D13입니다.
  3. LED 방향? 전원을 끈 뒤 양극과 음극을 확인합니다.
  4. GND 연결? 레일 중간 단절, 헐거운 점퍼선, 좌우 묶음 착각을 확인합니다.
  5. 저항값? 330 Ω과 330 kΩ은 다릅니다. 부품 표기나 측정값을 확인합니다.
  6. 모듈 규격? R/Y/G/GND 표기와 공통 음극·HIGH 점등 여부를 확인합니다.
전원 연결 전: 5V와 GND를 직접 연결하지 마세요. 출력 핀을 GND 또는 다른 출력 핀에 직접 연결하지 마세요. LED를 저항 없이 연결하지 마세요. 배선 변경은 전원을 분리한 뒤 진행하고, 발열·냄새가 나면 즉시 전원을 끄세요.

이 자료의 코드는 배선표와 대조했지만 실제 보드와 특정 모듈에서의 동작 시험을 대신하지 않습니다.
